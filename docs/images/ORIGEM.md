# Image sources

Correction, October 3, 2026: the supplied original schematic details `pb10-uart-r-tx-alias.png` and `j7-uart-r-pinout.png` establish PB10/U9 pin 29 → UART_R_TX → R36 (100 Ω) → J7 pin 2. PB11/U9 pin 30 → UART_R_RX → R37 → J7 pin 3. The remapped firmware serial port PC10/PC11 must not be conflated with those historical UART net names.

The assembly photographs and original schematics in this folder document my BT-Wheel build. They are not a universal board pinout.

The `software-*-en.jpg` files are real screenshots captured on October 2, 2026, with English selected, serial disconnected and temporary configuration storage. No motors were armed, tests executed or board settings written. The older Portuguese screenshots are retained but are not used by the English README/tutorial.
